## Who is Enterprise for?

Enterprise is designed for teams running voice agent evaluation in production where you need stronger identity controls, post-production analytics, and operational governance.

## Set up a license

Provide the enterprise license key either in environment variables or in config:

```bash title=".env"
EFFICIENTAI_LICENSE=eyJhbGciOi...
```

```yaml title="config.yml"
license:
  key: "eyJhbGciOi..."
```

Then restart the EfficientAI backend.

License scope behavior:

- If `org_id` is not set in the license payload, features are enabled deployment-wide.
- If `org_id` is set, features are enabled only for that organization.

Verify current state from API:

- `GET /api/v1/license-info`

## FAQ

### What happens without a license?

Feature-gated routes return a 403 with `enterprise_feature_required` (or `enterprise_license_required` for entitlement-only gates).

### What is the OSS usage analytics limit?

Open source deployments keep a 7-day usage analytics history by default.

### How do I verify whether my org is licensed?

Check `GET /api/v1/license-info` and confirm `enabled_features` is populated for your organization.

### Where do I configure authentication modes?

Use [Authentication guide](/docs/getting-started/authentication/) and [Configuration reference](/docs/reference/configuration/).
