# Python SDK

The Python SDK sends traces from your agent to EfficientAI. Each call shows up under **Observability → Calls**.

Start here. Then pick the next page for what you want to do.

## Before you start

1. Open the **workspace** where traces should appear.
2. Go to **Settings → API keys**.
3. Create a key and copy the workspace **ID**.

## Install

The SDK is not on PyPI yet. Install it from the repository:

```bash
pip install "efficientai-sdk[otel] @ git+https://github.com/EfficientAI-tech/efficientAI.git#subdirectory=sdks/python"
```

You need Python 3.9 or newer. The `otel` extra installs OpenTelemetry so spans can be exported.

## Configure

EfficientAI is self-hosted, so point the SDK at your deployment. Set these as environment variables, or load a `.env` file before constructing the client (the SDK does not load `.env` automatically):

```python
from dotenv import load_dotenv

load_dotenv()
```

Example `.env` or shell values:

```bash
EFFICIENTAI_BASE_URL=https://efficientai.your-company.com
EFFICIENTAI_API_KEY=...
EFFICIENTAI_WORKSPACE_ID=...
```

`EFFICIENTAI_BASE_URL` defaults to `http://localhost:8000` when you omit it.

You can also download a filled-in block from your deployment:

```bash
curl -s "$EFFICIENTAI_BASE_URL/api/v1/observability/traces/setup" \
  -H "X-API-Key: $EFFICIENTAI_API_KEY" \
  -H "X-Workspace-Id: $EFFICIENTAI_WORKSPACE_ID" | jq -r .env_block
```

## Check the key

```python
from efficientai_sdk import EfficientAI

EfficientAI().verify()  # True, or raises AuthenticationError
```

## Environment variables

| Variable | Purpose |
|---|---|
| `EFFICIENTAI_BASE_URL` | Your EfficientAI deployment (default `http://localhost:8000`) |
| `EFFICIENTAI_API_KEY` | API key from Settings → API keys |
| `EFFICIENTAI_WORKSPACE_ID` | Workspace that receives the traces |
| `EFFICIENTAI_OTLP_ENDPOINT` | Override the span ingest URL (default `<base URL>/api/v1/observability/traces`) |

## Upgrading from `efficientai.integrations.efficientai_traces`

The old helpers still work. They now live in `efficientai_sdk.tracing`. New code should use `trace.session()`. Unlike the old setup, it keeps concurrent calls in one process apart.
