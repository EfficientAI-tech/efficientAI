# Retell Integration

<IntegrationProviderNav active="retell" />

Retell integration connects externally hosted Retell agents to EfficientAI for evaluation workflows.

![Retell logo](/retellai.png)

## Configure

1. Open Configurations -> Integrations.
2. Add Retell credentials and connection details.
3. Save and verify the integration status.
4. In Agent configuration, set the integration and Retell agent ID.

## Use with EfficientAI

- Run external-provider comparisons with internal bundle runs.
- Use evaluator suites to score Retell call outcomes with shared metrics.
