# Plivo Integration

<IntegrationProviderNav active="plivo" />

Plivo integration is used for phone-number and telephony routing workflows that require PSTN execution paths.

<img
  src="/plivo.png"
  alt="Plivo logo"
  className="docs-provider-hero-logo"
  loading="lazy"
/>

## Configure

1. Open Configurations -> Integrations.
2. Add Plivo credentials.
3. Sync or map numbers as needed.
4. Use telephony-capable agent settings (`call_medium = phone_call`).

## Use with EfficientAI

- Test inbound and outbound phone-call flows.
- Evaluate telephony behavior alongside conversational quality metrics.
