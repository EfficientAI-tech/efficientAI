# Vapi Integration

<IntegrationProviderNav active="vapi" />

Vapi integration maps your Vapi agent configuration into EfficientAI test workflows.

![Vapi logo](/vapiai.jpg)

## Configure

1. Open Configurations -> Integrations.
2. Add Vapi credentials.
3. Save and confirm integration health.
4. In Agent setup, set the Vapi integration and provider agent ID.

## Use with EfficientAI

- Run scenario-driven tests on Vapi-backed calls.
- Score outcomes with the same evaluator and metric suite used elsewhere.
