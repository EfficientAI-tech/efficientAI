# Twilio Integration

<IntegrationProviderNav active="twilio" />

Connect Twilio for phone calls and SMS-based agent testing.

## Configure

1. Open **Configurations → Integrations** and add your Twilio account.
2. Import your numbers under **Telephony Numbers**.
3. When creating an agent, choose the path that matches production (telephony or messaging) and select your Twilio number in the wizard.
