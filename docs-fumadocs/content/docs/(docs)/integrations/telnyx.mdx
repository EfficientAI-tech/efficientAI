# Telnyx Integration

<IntegrationProviderNav active="telnyx" />

Connect Telnyx for phone calls and SMS-based agent testing.

## Configure

1. Open **Configurations → Integrations** and add your Telnyx API key and webhook settings.
2. Import your numbers under **Telephony Numbers**.
3. When creating an agent, choose the path that matches production (telephony or messaging) and select your Telnyx number in the wizard.
