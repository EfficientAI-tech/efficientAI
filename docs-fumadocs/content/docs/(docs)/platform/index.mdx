# How It Works

EfficientAI evaluates voice agents the way your customers experience them: by placing real
calls against the production agent and driving those calls with simulated callers.

Everything on the platform is built from a small set of objects. Each one is explained on its own
page in this section — this page shows how they fit together.

## The object model

An **evaluation suite** groups one production agent with persona and scenario combinations. Each combination
becomes one or more **runs**, and each run is scored by the **metrics** you enabled.

### Combination math

Evaluation suite runs use persona–scenario pairing:

- If personas and scenarios are selected in the suite, total combinations are `P × S` (Cartesian product).
- Run count multiplies that total (for example, 10 combinations × 3 runs = 30 calls).

## The evaluation lifecycle

Because persona, scenario, and voice mapping are pinned configuration, re-running a suite after a
prompt or model change produces a comparison you can trust rather than a one-off anecdote.
