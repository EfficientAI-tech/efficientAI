# Playground

Agent Playground is a way to talk to either the EAI test agent or your production agent—to test the
connection manually before simulated calls, so you can tweak a few things first.

## What it does

From one place, you can:

- Start live tests
- Monitor call/test status
- Inspect transcripts and recordings
- Compare test-agent and voice-agent behavior

## Test modes

### Voice AI Agent mode

Uses external provider configuration and runs a live web call against your production agent on the provider.

Supported providers commonly include Retell, Vapi, and ElevenLabs.

Typical flow:

1. Create a web call with the selected production agent.
2. Connect through provider session/client.
3. Store call recording metadata.
4. Poll provider call details (status, transcript, audio).
5. Create evaluator result and run metrics.

Provider timing on these runs comes from the voice platform, not **Pipeline trace** rows in
**Observability → Calls**. See [Traces and Logs](/docs/platform/traces-and-logs/).

### Test Agent mode

Uses the internal EfficientAI voice path with your configured voice bundle. This is useful for controlled comparisons of STT, LLM, and TTS choices.

When pipeline tracing is enabled for your deployment, **Listen / Think / Speak** appears on the Playground result → **Call details** → **Pipeline**.

## Prerequisites

For external live web-call testing:

- `call_medium: web_call`
- `voice_ai_integration_id` configured
- `voice_ai_agent_id` configured
