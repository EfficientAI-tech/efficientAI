# Agent

Agents in EAI are test agents you use to evaluate your production agent.

Each one holds your production prompt and how EfficientAI reaches that bot when you run a test—not
the live bot your customers use on its own.

## How you connect to production

In **Create Agent**, pick the path that matches how production runs today:

| Path | Best when | What you set up |
| --- | --- | --- |
| **Telephony** | Customers reach you on a phone number | A telephony provider (Plivo, Twilio, Telnyx, Vobiz, …) and an imported number |
| **Platform integration** | You use a voice AI platform | Retell, Vapi, ElevenLabs, Smallest, or similar — connect in the wizard |
| **Messaging** | Production is SMS or chat-style | A messaging-capable number and the channel shown in the wizard |

Every path uses the same **personas**, **scenarios**, and **metrics** — only the connection step changes.

Set up [Integrations](/docs/integrations/) first if your path needs credentials or phone numbers.

## Configure an agent

### What you configure

- Agent identity (name, language)
- Inbound or outbound behavior and how EfficientAI reaches your bot
- Internal voice bundle mapping
- External voice-platform mapping (integration + provider agent ID)
- Test prompt and provider prompt surfaces

### Creating a test agent

Use **Create Agent** and follow the wizard for your connection type. You add your production prompt
(or sync it from the provider) and a test prompt EfficientAI uses during evaluations.

### Prompts

Add your production prompt (or sync from the provider) and the test prompt EfficientAI uses during
evaluations. Use **Generate test prompt** to draft the test prompt from production, then edit as needed.

### Recommended flow

1. Create a voice bundle and required integrations — see [Setup](/docs/platform/setup/).
2. Create a test agent.
3. Attach [personas](/docs/platform/persona/) and [scenarios](/docs/platform/scenario/) through
   [evaluation suites](/docs/platform/evaluation-suite/).

See also: [How It Works](/docs/platform/) for how the agent connects to the rest of the object model.

## How to set up an agent

1. Go to **Simulations > Agents** in the left navigation.
2. Click **Create Agent** in the top-right.

![Creating an agent](/screenshots/Agents/Agent_homepage.png)

### If you choose telephony

Enter:

- Name
- Phone number
- Language (the language EfficientAI uses with your bot)
- Call type (`outbound` or `inbound`)
- End call after silence (how many silence seconds before hang up)

![Telephony agent setup](/screenshots/Agents/Agent_telephony.png)

Then configure your phone integration in [Integrations](/docs/integrations/).

### If you choose web agent

1. Enter the agent name.
2. Open your provider (Vapi, ElevenLabs, Retell, Smallest, and others).
3. Click **Connect** so EfficientAI can fetch available provider agent IDs.
4. If needed, enter the provider agent ID manually.

![WebRTC agent setup](/screenshots/Agents/Agent_webRTC.png)

If your provider is missing, open an issue on [GitHub](https://github.com/EfficientAI-tech/efficientAI/issues/new).

### Prompt

You can copy and paste the prompt you have set for your production agent here. EfficientAI can create an
adversarial prompt when you choose an AI provider, LLM model, and provide additional context.

For first message behavior, choose:

- **Production agent speaks first** (default)
- **Test caller speaks first** (the EfficientAI test agent starts)

For the EfficientAI system prompt, define:

1. Role and goal
2. Talking style
3. Questions to ask
4. Information to relay
5. Constraints

![Prompt partial setup](/screenshots/Agents/Agent_prompt_partial.png)

### Voice bundle

Select the voice bundle you want for the EAI test agent.

For how to create bundles, see [Setup](/docs/platform/setup/) and [Persona](/docs/platform/persona/).

Create the agent to finish setup. Editing flow and custom agent testing docs are coming soon.
