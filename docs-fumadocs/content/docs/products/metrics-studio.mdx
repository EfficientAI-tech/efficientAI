# Metrics Studio

Metrics Studio lets you experiment with metrics against ad-hoc call sources.

Metrics Studio is under **Metrics → Studio**. The Studio page has two areas:

- **Setup** — start a new evaluation with **New evaluation** (guided wizard).
- **Results** — browse past Studio runs and open run detail for scores, audio, and transcripts.

## New evaluation wizard

The wizard walks through three steps in a full-screen modal:

1. **Calls** — choose call import rows (search by conversation ID or row UUID), playground / observability recordings, or simulated evaluator results. Use **Select all matching** on import rows to include every row that matches your search.
2. **Metrics** — select **Active** (enabled) metrics or **Draft** metrics you are iterating on. You can create a draft metric inline and promote drafts when ready.
3. **LLM & run** — optional run name, transcript source (diarised or production CSV), and evaluation model. Leave the model blank to use your organization default; choose a credential to pin gateway routing. Then **Run evaluation**.

After a run starts, you land on run detail. **Back to Studio results** returns to the Results tab.

The **Active** metrics list includes only metrics enabled in your current workspace. Disabled metrics stay on the **Manage** tab until you turn them on. Draft metrics stay hidden from Call Import evaluations and the Manage tab until promoted.
