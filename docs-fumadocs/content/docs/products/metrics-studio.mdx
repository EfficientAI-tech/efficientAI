# Metrics Studio

Metrics Studio lets you experiment with metrics against ad-hoc call sources.

Metrics Studio is a sub-tab under **Metrics → Studio**. Use it to:

1. Select **enabled** metrics for the active workspace, or **draft** metrics you are iterating on
2. Pick call sources from call imports, playground/observability recordings, or simulated evaluator results
3. Run ad-hoc evaluations and inspect per-metric scores
4. Promote draft metrics to production when satisfied

The **Active** tab lists only metrics that are enabled in your current workspace. Disabled metrics stay on the **Manage** tab until you turn them on. Draft metrics stay hidden from Call Import evaluations and the Manage tab until promoted.
