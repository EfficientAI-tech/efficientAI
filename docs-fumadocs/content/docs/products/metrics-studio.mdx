# Metrics Studio lets users experiment with metrics against ad-hoc call sources.

Metrics Studio is a sub-tab under **Metrics → Studio**. Use it to:

1. Select active or **draft** metrics
2. Pick call sources from call imports, playground/observability recordings, or simulated evaluator results
3. Run ad-hoc evaluations and inspect per-metric scores
4. Promote draft metrics to production when satisfied

Draft metrics stay hidden from Call Import evaluations and the Manage tab until promoted.
