# Evaluators

## What is an Evaluator Suite?

An **Evaluator Suite** groups one **Agent**, one **Persona**, and **multiple Scenarios** into test combinations.

Each scenario becomes one combination (1:1:N). You can:

- Choose **metrics** to score at the suite level (optional — defaults to all enabled agent metrics)
- **Outbound / web**: run every combination **X times** (total runs = N × X)
- **Inbound**: use **round-robin** — each test-initiated call uses the next scenario in rotation

---

## Creating a Suite (4-step wizard)

1. **Agent & Persona** — pick one agent and one TTS-compatible persona
2. **Scenarios** — multi-select scenarios (each becomes a combination)
3. **Metrics** — optional metric picker
4. **Review** — name, tags, default runs per combination

---

## Running

| Agent type | Behavior |
|---|---|
| Web call | Queue Celery bridge runs for all combinations × runs |
| Phone outbound | Batch outbound calls (requires dial target) |
| Phone inbound | **Run next combination** — round-robin through scenarios |

---

## API

| Method | Path | Purpose |
|---|---|---|
| POST | `/api/v1/evaluator-suites` | Create suite + combinations |
| GET | `/api/v1/evaluator-suites` | List suites |
| POST | `/api/v1/evaluator-suites/{id}/run` | Batch run (outbound/web) |
| POST | `/api/v1/evaluator-suites/{id}/run-next` | Inbound round-robin single run |

Legacy single-evaluator endpoints remain for backward compatibility.
